# Card templates

## Experiment card

```markdown
### Experiment [N] — [short name]

**Assumption:** We believe that [assumption, verbatim from the map].

**Lens:** [Desirability / Feasibility / Viability / Impact / Equity & harm] · **Importance:** [1–5] · **Evidence now:** grade [0–5]

| | |
|---|---|
| **To test it, we will** | [Method, concretely: who, how many, where, what they see or are asked to do, for how long] |
| **And measure** | [One primary metric, defined so two people would count the same result] |
| **We're right if** | [Success threshold — a number] |
| **We'll stop or rethink if** | [Kill threshold — a number] |
| **In between means** | Inconclusive — [what we'll do] |
| **Evidence this gives us** | Grade [0–5] |
| **Also watch** | [1–3 secondary observations — not decision criteria] |
| **Cost** | [£ / staff days] |
| **Time** | [Start → end] |
| **Owner** | [Role] |

**If we're right:** [next step]
**If we stop:** [next step]
**If inconclusive:** [next step]

**Known limits:** [what this test can't tell us]
```

## Learning card

```markdown
### Learning card — Experiment [N]: [short name]

**Assumption tested:** We believe that [verbatim].
**Thresholds set in advance:** right if [X]; stop if [Y].

**What we did:** [Method as actually run, including anything that changed from the plan and why]

**What we observed:**
- [Numbers first]
- [Notable things people did]
- [Notable things people said — labelled as opinion]

**Against the thresholds:** [Success / Kill / Inconclusive] — [one line]

**What we learned:** [Interpretation, clearly separated from observation]

**New evidence grade:** [0–5] (was [0–5])

**Decision:** [Persevere / Pivot / Kill / Re-run] — [why]

**Next riskiest assumption:** We believe that [...]
```
